# 🧠 Math-CS Learning Platform

> **Mathematics meets Computer Science.**

A modern educational platform designed to bring **Mathematics, Computer Science and interactive learning** together in one place.

---

## 🚀 About the Project

**Math-CS Learning Platform** is an educational web project focused on making technical subjects more interactive, accessible and engaging.

The platform combines:

* 📐 Mathematics
* 💻 Computer Science
* 🧩 Interactive Quizzes
* 🎯 Learning Challenges
* 📊 Progress Tracking
* 🏆 XP & Gamification
* 👤 User Accounts

---

## ✨ Features

### 📐 Mathematics

Explore mathematical topics through an interactive learning experience.

### 💻 Computer Science

Learn programming and computer science concepts with structured content.

### 🧩 Interactive Quizzes

Test your knowledge with timed quizzes and challenge-based questions.

### 🔥 Hard Mode

A more challenging quiz experience with:

* ⏱️ Time limits
* ⚡ Faster decision making
* 🎯 Passing requirements
* 🧠 Higher difficulty questions

### 🏆 Gamification

Earn **XP**, complete challenges and track your learning progress.
